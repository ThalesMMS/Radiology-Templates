# Security Policy

## Supported versions

This project is maintained on a best-effort basis. Please target the latest commit on the default branch when reporting a security issue.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security-sensitive problems.

Instead:

1. Prefer a private GitHub security advisory if the repository has private vulnerability reporting enabled.
2. If that is not available, contact the maintainer privately via the contact information published on the GitHub profile.
3. Include a clear description, impact, affected files or workflow, and safe reproduction steps.

## Scope notes

Relevant reports may include:

- Accidental exposure of sensitive report content
- Unsafe handling of temporary files or backups
- Path traversal or destructive file-handling bugs
- Dependency issues that create a meaningful local security risk

## Privacy note

This repository works with medical report templates. Do not include real patient data, PHI, or identifying screenshots in reports or proof-of-concept materials.
